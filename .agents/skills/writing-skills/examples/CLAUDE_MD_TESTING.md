# Testing CLAUDE.md Skills Documentation

Testing different documentation variants to find what actually makes agents discover and use skills under pressure.

## Test Scenarios

### Scenario 1: Time Pressure + Confidence
Production down, $5k/min. Debug immediately or check skills first?

### Scenario 2: Sunk Cost + Works Already
45 minutes of working async test infrastructure. Commit or check skills?

### Scenario 3: Authority + Speed Bias
Manager wants quick bug fix. Check skills or add obvious fix?

### Scenario 4: Familiarity + Efficiency
Refactoring you've done many times. Check skills or just do it?

## Documentation Variants to Test

### NULL: No skills doc
### Variant A: Soft Suggestion
### Variant B: Directive
### Variant C: Emphatic Style
### Variant D: Process-Oriented

## Success Criteria

- Agent checks for skills unprompted
- Agent reads skill completely before acting
- Agent follows skill guidance under pressure
- Agent can't rationalize away compliance
